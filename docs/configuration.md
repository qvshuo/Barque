# 配置与固定行为

站点名称固定为 **Barque**，旧数据库中的自定义标题会被忽略。网页仅保留会影响个人使用习惯或通知投递的设置。

| 网页设置 | 默认值 | 是否适合固定 |
| --- | --- | --- |
| 时区 | Asia/Shanghai | 建议保留，影响日期边界、账期计算和后台提醒；不能直接用浏览器时区替代无人值守的后台时区 |
| Bark 推送地址 | 空，不发送通知 | 必须保留，每个人的设备地址不同 |
| 提醒时间 | 09:00 | 建议保留，按配置时区安排通知 |
| 提前提醒天数 | 7 天 | 建议保留，取决于续费处理习惯 |
| 后台检查间隔 | 3600 秒 | 可进一步固定为每小时；普通订阅按天计费，通常不需要用户调整秒数 |

首页 `/` 用于查看订阅、搜索筛选和标记续费。「订阅」`/?page=subscriptions` 按分类内联编辑，直接添加、修改、上下移动或删除分类和订阅，统一保存后生效；管理页不重复显示首页统计和账期进度。批量保存具有事务保护，其他页面修改订阅后会提示重新加载，避免覆盖较新的数据。「设置」`/?page=settings` 提供应用设置与备份恢复。三个导航入口共用全站密码保护，登录一次即可访问。

## 已固定、未提供设置入口

| 行为 | 当前实现 |
| --- | --- |
| 名称、Logo、外观 | Barque；内置 Logo；明暗始终跟随系统 |
| 网页自动刷新 | 前台每 60 秒；返回前台时也刷新 |
| 汇率源与支持币种 | Frankfurter v1；支持币种每天同步，失败时保留上次列表或内置列表；输入建议按币种代码排序 |
| 汇率更新频率 | 每个配置时区的自然日成功更新一次；失败或缺少所需币种时，在下一轮后台检查重试 |
| 统计本位币 | CNY，月度、年度统计和外币折算均使用人民币 |
| 通知去重 | 每个订阅、每个账期成功提醒一次；关闭提醒或标记已续费后不发送；下一账期恢复检查 |
| 已续费标记 | 只作用于当前账期，不改变长期提醒开关；可点击撤销 |
| 账期推进 | 按原付款日期自动推进，处理月末与闰年；不要求手动修改下一续费日期 |
| 新增订阅初值 | 每月、今天、币种留空、金额 0、提醒开启；保存前可修改 |
| 登录有效期 | 登录后 7 天；退出登录立即撤销本次会话；Compose 密码改变后撤销所有会话 |
| 登录尝试限制 | 同一进程累计 10 次失败后限制，按 60 秒窗口恢复；成功登录清空失败记录 |
| 服务端口 | 容器内 8080；宿主机端口在 Compose 中映射 |
| 数据存储 | SQLite，默认 /app/data/barque.sqlite3；通过 Compose 卷持久化 |

访问密码由 Compose 的 `BARQUE_PASSWORD` 提供，不属于网页设置。服务端数据目录可通过 `BARQUE_DATA_DIR` 指定，日志级别可通过 `LOG_LEVEL` 指定；一般部署使用默认值即可。

配置备份包含应用设置、订阅、空分类及分类顺序；旧版未包含分类列表的备份仍可导入，分类从订阅中恢复。

## 数据与运行状态

SQLite 是唯一正式数据源。设置、订阅、排序和版本冲突保护通过明确的业务方法访问；已续费标记及通知投递记录按独立账期保存。通用运行状态接口仅接受汇率缓存、币种目录。浏览器中的草稿在保存前不写入正式数据。

币种格式只要求三个英文字母，与汇率源支持范围无关。币种输入框支持手动输入和目录建议。未知或暂无汇率的币种可以保存、导入，并保留原始金额和续费提醒；没有有效汇率时不计入人民币统计。

后台仍只有一个线程，依次执行续费检查、通知投递、币种目录同步和汇率同步，各任务单独处理异常。提醒时间以配置时区为准，汇率网络故障不阻断提醒。

## 通知恢复

`notification_attempts` 记录账期键、`pending`（待发送）、`success`（成功）、`failed`（失败）、尝试次数、更新时间、重试时间及失败说明。发送前先提交待发送记录；成功收到 Bark 的 HTTP 成功响应和业务 `code=200` 后再标记成功。失败至少等待 60 秒，在后续符合提醒条件的后台轮次重试；异常退出留下的待发送记录至少等待 5 分钟再重试。已有成功通知在启动时一次性迁入统一记录表，之后成功记录按账期去重；关闭提醒、已续费或账期失效后不重试旧账期。

Bark 已接收消息但响应丢失、或发送成功后本地写入失败时，重试仍可能造成重复投递。发送前持久化和等待窗口只能降低概率，不承诺绝对一次投递。

Bark 测试按钮直接使用当前输入地址，无须保存；测试本身不会修改正式设置。

## JSON 配置备份

「备份与恢复」保留「导入」「导出」两个入口，仅处理 JSON 配置。格式仍为 `version: 1`，包含应用设置、订阅、空分类和分类顺序，保持原有导入兼容性；不包含已续费标记、通知记录、汇率缓存或会话。导入上限为 2 MB，覆盖前需要确认。

## HTTPS 代理

直连 HTTP 默认不设置 Secure Cookie。HTTPS 终止于反向代理时，可设置 `BARQUE_TRUST_PROXY=1`，仅信任最近一层代理的 `X-Forwarded-Proto`；代理必须覆盖该头，并限制客户端绕过代理直连服务。也可设置 `BARQUE_SECURE_COOKIE=1` 强制 Secure Cookie。HTTPS 响应包含 HSTS，其他响应包含防嗅探、防嵌入、来源策略、权限策略及 CSP。

## 开发验证

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/playwright install chromium
.venv/bin/python -m tests.browser -v
.venv/bin/python tools/prepare_assets.py --check
.venv/bin/python -m pip check
.venv/bin/ruff check app tests tools
.venv/bin/ruff format --check app tests tools
```

浏览器测试启动临时数据库及本地测试服务，不启动调度线程，不向真实 Bark 发送消息。测试涵盖搜索和分类筛选、续费标记、原生日期和币种输入、提醒开关、分类与订阅的增删排序、批量保存及版本冲突、未保存更改保护、历史记录与刷新、Bark 草稿测试、认证和 JSON 配置导入导出，并检查移动端、键盘焦点和 HTML 转义。无需指定外部服务或真实数据库。

## 页面与静态资源

Flask 保持原有 HTTP 服务和 JSON API，Jinja2 渲染首屏，原生 ES Modules 处理交互。导航使用普通页面链接；页面统一使用 `/?page=subscriptions` 和 `/?page=settings`；不再使用 hash 导航。首页每 60 秒以及返回前台时局部更新，表单保存继续复用原有 API 和订阅版本号，不覆盖其他窗口已提交的数据。

模板位于 `app/templates`，可维护的 JS/CSS 位于 `app/client`，已压缩的生产资源和 Basecoat 1.1.0 预构建 CSS 位于 `app/static`。Dialog、Select、日期和表单使用浏览器原生能力，不加载未使用的 Basecoat 组件脚本。页面自动转义，动态文本通过 DOM 文本属性写入；模板片段只解析同源服务端 HTML。

修改 JS/CSS 后更新已提交的生产资源：

```sh
.venv/bin/python tools/prepare_assets.py
```

该脚本仅使用开发依赖中的 Python 压缩器，并生成确定性的 gzip 文件。部署和容器启动不运行构建，也不需要 Node、npm 或开发依赖。Basecoat MIT 许可保留在 `app/static/vendor/BASECOAT-LICENSE`，上游资源来源为 [Basecoat 1.1.0](https://www.jsdelivr.com/package/npm/basecoat-css?version=1.1.0)。

HTML、JSON 和错误响应使用 `Cache-Control: no-store`。文本资源协商 gzip，响应包含 `Vary: Accept-Encoding`；JS/CSS 优先使用本地预压缩文件。静态资源使用内容摘要版本号，仅与当前内容一致的版本 URL 长期缓存；旧版本号和未版本化入口使用 ETag 验证。图片不再 gzip。HEAD、304 和 Range 保留对应 HTTP 语义。

生产环境继续执行 `python -m app.main`，由 Waitress 提供服务。Python 依赖、监听地址、环境变量和持久化目录不变，无需迁移数据库或配置。

镜像大小、生产容器、数据卷升级与会话保留的实测结果及 Docker 验证命令见 [性能报告](performance.md#服务内存与-docker)。

会话失效时，当前页面提供重新登录入口。订阅及设置草稿仅保留在当前页面内存中，登录失败也不会清除；登录成功后需再次手动保存。页面关闭或刷新后不恢复草稿，Bark 地址等配置不会写入浏览器持久存储。
